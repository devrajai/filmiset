Catalog Google Sheet se aata hai

Is site ka catalog ek Google Sheet (old & classic movies collection) se aata hai — data/movies.json ke through load hota hai. Sheet update karo, JSON dobara banao, aur site khud refresh ho jaati hai. Neeche embedded demo titles fallback ke liye hain.

Real banane ke liye: TMDB API key (free) se titles, genres, language, posters — aur JustWatch/Streaming Availability se "kahan dekho". Dubbed-Hindi aur Gujarati-natak ka data manually curate karna padega.
