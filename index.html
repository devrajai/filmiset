Catalog free internet sources se aata hai

Is site ka catalog do jagah se aata hai: ek Google Sheet se curate kiya hua (data/movies.json), aur ek Wikidata se automatically collect kiya hua (data/catalog.json — roz ek GitHub Action se refresh hota hai). Dono free hain, koi API key nahi chahiye. Neeche embedded demo titles fallback ke liye hain.

Real banane ke liye: TMDB API key (free) se titles, genres, language, posters — aur JustWatch/Streaming Availability se "kahan dekho". Dubbed-Hindi aur Gujarati-natak ka data manually curate karna padega.
